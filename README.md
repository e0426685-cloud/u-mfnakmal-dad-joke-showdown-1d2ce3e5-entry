One original dad joke, 200 characters or fewer, written from scratch: a father takes "make the bed" far too literally.

```
I asked Dad if he was going to make the bed. He said, 'Yes — what kind of wood should I use?'
```

## Run it

```sh
python3 main.py
```

Writes the joke to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set).
